# Port-a-poly

A true portable analog polyphonic synth. Working name from Adam (2026-11-21): "Port-a-poly is an amazing name for the portable poly tho."

Status: **not started**. Build plans come after the string machine's. Which instrument gets built first is undecided.

## What Adam has said (verbatim, 2026-11-21)
- "I like the synths you mentioned more than the model d sound wise. Just chose model d for simplicity. Polyphonic would be amazing."
- "I'm more thinking the portability factor."
- What draws him: "Analog voices, shimmer and warmth"
- "Right now I'm thinking big energy is the model d clone with 4 voice paraphony, port-a-poly is the true poly, and the string machine needs a cool name"

## Context from chat (not decisions)
- He likes blending several oscillators per voice, and the Juno's chorus and warmth. He built a Dreadbox Antiphon (8 analog sine oscillators, spring reverb).
- He is skeptical of mixing analog and digital voices inside one chord: "if it hasn't been done before it may be for a reason".

## Ideas discussed, none decided
- Juno-style DCO voices, or an SEM-style state-variable filter per voice.
- The Daisy runs envelopes, LFOs and voice allocation, plus the ensemble/chorus, reverb and echo.
- 4–6 voices.
- A separate mode where digital oscillators feed the analog filters (Novation Peak/Summit-style).

## Research so far
- [Polyphonic and hybrid clones](../explore/poly-hybrid.md) (2026-11-13): a 4-voice Juno-style "Little J" at ≈ $350–520, and a Prophet-600-ish voice at ≈ $380–560, for one unit. Both are estimates.
- Reference: the Behringer Pro-800 has 8 voices with 2 CoolAudio 3340 VCOs and a V3320 filter per voice. Its envelopes and LFO are computed in firmware (checked in GliGli's open p600fw).
